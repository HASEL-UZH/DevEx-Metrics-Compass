## **How to Run the Compass** 

***

### **Locally** 

1.  **Open the Terminal**.
2.  Navigate to the directory containing the Compass files using the `cd` command. For example:
    ```bash
    cd "path to directory with index.html"
    ```
    The directory must contain the following files:
    * `index.html`
    * `script.js`
    * `style.css`
    * `data.json`
    * `source_ids.json`
    * `favicon.png`
    * `uzh-logo.svg`
3.  Run a simple HTTP server by entering the following command:
    ```bash
    python -m http.server
    ```
    
4.  Open your web browser and go to `http://localhost:8000/index.html`.

***

### **Web Server** 

1.  **Upload all the Compass files** to the web server. All files must be in the same directory.
    The directory must contain these files:
    * `index.html`
    * `script.js`
    * `style.css`
    * `data.json`
    * `source_ids.json`
    * `favicon.png`
    * `uzh-logo.svg`
    * `robots.txt`
    * `sitemap.xml`
    * the `library/` folder (static SEO landing pages, generated by `dataset/generate_seo_pages.py`)
2.  Navigate to `index.html` on your web server to view the Compass.
