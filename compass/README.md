## **How to Run the Compass** 

***

### **Locally** 

1.  **Open the Terminal**.
2.  Navigate to the directory containing the Compass files using the `cd` command. For example:
    ```bash
    cd "path to directory with index.html"
    ```
    The directory must contain the following files:
    * `index.html`
    * `script.js`
    * `style.css`
    * `data.json`
    * `source_ids.json`
    * `favicon.png`
    * `uzh-logo.svg`
3.  Run a simple HTTP server by entering the following command:
    ```bash
    python -m http.server
    ```
    
4.  Open your web browser and go to `http://localhost:8000/index.html`.

***

### **Web Server** 

1.  **Upload all the Compass files** to the web server. All files must be in the same directory.
    The directory must contain these files:
    * `index.html`
    * `script.js`
    * `style.css`
    * `data.json`
    * `source_ids.json`
    * `favicon.png`
    * `uzh-logo.svg`
    * `robots.txt`
    * `sitemap.xml`
    * the `library/` folder (static SEO landing pages, generated by `dataset/generate_seo_pages.py`)
    * the `api/` folder (telemetry, feedback and report endpoints; requires PHP)
    * the `stats/` folder (the usage dashboard; requires PHP)
2.  Navigate to `index.html` on your web server to view the Compass.

***

### **`stats/` — usage dashboard**

A password-protected dashboard at `/stats/` that reads the logs the `api/` endpoints write
and turns them into usage insight: session counts and journey funnel per timeframe, the most
used metrics, companies, frameworks, comparisons and searches, the feedback and "report
something missing" inboxes, and a per-session drill-down that can rebuild the link to reopen
the Compass as that visitor left it. It only ever reads the logs.

Its configuration (the password hash) lives outside the web root and is never committed —
see `stats/compass-stats-config.example.php` for where it goes and why.
