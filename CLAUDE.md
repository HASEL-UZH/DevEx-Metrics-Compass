# DX-Metrics-Compass

Interactive dashboard for navigating developer experience (DevEx) metrics across research and industry.

## Stack

- Vanilla HTML, CSS, JavaScript (no build tool, no framework, no npm)
- AnyChart v8 (CDN) for the sunburst visualization
- Python (parser only, not part of the dashboard)
- Served locally via `python -m http.server`, deployed to a public FTP web server

## Project Structure

The repo has two independent parts:

- `dashboard/` — the web app (primary working area); see [dashboard/README.md](dashboard/README.md)
- `metrics and parser/` — the Excel source file and Python parser that generate `data.json` and `source_ids.json`; see [metrics and parser/README.md](metrics%20and%20parser/README.md)

Work almost exclusively happens in `dashboard/`.

## Conventions

- No emoji in code or UI text (existing emoji in filter labels are intentional; do not add new ones)

## Branch Strategy

- `main` — stable, deployable branch
- `dev` — day-to-day working branch for simple changes
- feature branches (e.g. `add-comparison-step`) — for larger changes, branched off `dev`

## Forbidden

- Never edit `dashboard/data/data.json` or `dashboard/data/source_ids.json` directly — they are generated by `metrics and parser/parser.py` and any manual edits will be overwritten on the next parser run
- Do not add external JS libraries or CSS beyond what is already loaded in `dashboard/index.html` without asking first
- `node_modules/`, `dist/`, `build/`, `.git/`, `coverage/`

## Compact Instructions

When compacting, focus on: code changes made, UI behaviour affected, decisions taken, and current task state.
